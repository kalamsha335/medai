# 🩺 Med AI – AI-Powered Medical Assistant

**Technologies:** Python, Flask, HTML, CSS, JavaScript, TensorFlow, Machine Learning, MySQL

**Project Overview**

Med AI is an intelligent healthcare web application designed to assist users by providing AI-powered preliminary health insights based on symptoms. The platform combines machine learning with a user-friendly interface to help users better understand potential health conditions and encourage timely medical consultation.

### ✨ Key Features

* 🤖 AI-based symptom analysis and disease prediction
* 🔐 Secure user authentication and profile management
* 📋 Interactive symptom input interface
* 📊 Machine learning model for health prediction
* 🩺 Personalized health recommendations
* 📈 User-friendly dashboard to view prediction history
* 💻 Responsive web interface accessible across devices

### 🛠 Tech Stack

* **Frontend:** HTML, CSS, JavaScript, Bootstrap
* **Backend:** Python, Flask
* **Machine Learning:** TensorFlow, Scikit-learn
* **Database:** MySQL
* **Tools:** Git, GitHub, VS Code

### 🎯 Key Highlights

* Developed an AI-powered healthcare assistant using Python and Flask.
* Integrated a machine learning model to predict possible diseases from user symptoms.
* Designed a secure authentication system and responsive web interface.
* Managed user data and prediction history using a MySQL database.
* Focused on improving accessibility and user experience through an intuitive design.

> **Note:** Med AI is intended for educational and research purposes only. It does not replace professional medical advice, diagnosis, or treatment.
